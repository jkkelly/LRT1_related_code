# LRT1_related_code
This is a collection of programs to analyze allele frequency divergence among populations.  Each population is composed of one or more replicated samples that have been sequenced as pools. 
These populations could be experimental units subject to one or more generations of selection under different treatments.
They could be the ancestral and derived populations of a selection experiment, a.k.a. experimental evolution.
They could be natural populations that have diverged in a response to a particular ecological factor, e.g. neighboring plant populations that occur on contaminated soils or not.
The basic approach is applicable to all these cases, although the details of the model and how the model is fit will differ depending on design features.

The user modifies to the Control.txt file to specify their input file and parameter values.  This is a tab delimited text file (make sure there are no unwanted spaces in the revised text).
